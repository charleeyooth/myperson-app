# MyPerson

### Dating App with Verification, Matching & Intelligent Coaching Notifications

MyPerson is a dating application built around user profiles, verification, matching, relationship-oriented flows, and an intelligent notification coaching system.

This repository is a **public portfolio showcase**. The private application source code, credentials, production data, and internal logic are not included.

## Product Experiences

- onboarding and profile flows
- authentication
- user profiles
- matching
- verification workflows
- admin verification review
- notifications
- intelligent coaching notifications
- relationship-oriented product experiences

## Engineering Work

Development has included:

- React Native product screens
- Firebase-backed workflows
- per-user local storage patterns
- push and local notifications
- admin verification tooling
- profile-state management
- debugging and iterative UI refinement
